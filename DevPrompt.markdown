# DevPrompt.md: Универсальный промт для разработки интеллектуальной системы инвестиционных рекомендаций

## Введение
Этот файл — универсальный промт для включения ИИ или разработчика в разработку desktop-приложения для среднесрочного инвестирования на Московской бирже (MOEX) с AI-советником. Он описывает проект, ключевые документы, структуру документации и инструкции для работы на любом этапе. Промт можно использовать, загрузив вместе с проектом (или ссылкой на Git-репозиторий) и указав текущую стадию, задачу и проблемы. ИИ/разработчик может задавать уточняющие вопросы, чтобы влиться в процесс.

**Цель**: Обеспечить контекст, чтобы ИИ или разработчик могли начать работу с чётким пониманием проекта, текущего состояния и требований. Промт поддерживает модульный подход, основанный на `ModularityConcept.md`, и гарантирует согласованность с `InvestmentAdvisorDetailedPlanWithUI.md` и `DevelopmentApproachAndIndex.md`.

## Обзор проекта
- **Описание**: Desktop-приложение для одного пользователя, предоставляющее утренние рекомендации "купить/продать/держать" на основе технического анализа, новостей и AI (Scikit-learn: RandomForest, GradientBoosting, SVM). Поддерживает оффлайн-режим (DuckDB), импорт портфеля (CSV/XLSX), backtesting, paper trading и самообучение с human feedback.
- **Технологии**: Python 3.9+, PyQt5, DuckDB, Scikit-learn, pandas_ta, feedparser, schedule.
- **Архитектура**: Модульный монолит с ABC интерфейсами (`AnalyzerInterface`, `DataProvider`), pydantic для типизации, Dependency Injection (DI) через `config.py`/`config.yaml`. Хуки для asyncio, FastAPI/gRPC, PyTorch, PostgreSQL.
- **Репозиторий**: Локальный или GitHub ([INSERT_GIT_LINK]). Структура: `src/`, `tests/`, `docs/specs/`, `logs/`, `models/`, `scripts/`.
- **Текущая дата**: 15 октября 2025, 14:22 CDT.

## Ключевые документы
Эти файлы подгружаются вместе с промтом и содержат полное описание проекта:
- **`InvestmentAdvisorDetailedPlanWithUI.md`**:
  - Полный план: пользовательский сценарий, функции (портфель, рекомендации, анализ, AI), UI (PyQt5, вкладки, диалоги), архитектурная схема, фазы разработки (1–4).
  - Где искать: Концепция проекта, интерфейсы, спецификации.
- **`DevelopmentApproachAndIndex.md`**:
  - Подход к разработке: MVP с масштабируемостью, модульность, Git-воркфлоу, тестирование.
  - Индекс документации: Ссылки на `docs/specs/StepX.Y-<Name>.md` для каждого шага.
  - Где искать: Структура фаз/шагов, документация по модулям.
- **`ModularityConcept.md`**:
  - Принципы модульности: ABC интерфейсы (`AnalyzerInterface`, `DataProvider`), pydantic контракты (`AnalyzerInput`, `AnalyzerOutput`), DI (`config.yaml`), тестирование (unit, integration, E2E).
  - Где искать: Регламент для кода, контрактов, Git.
- **Документация по шагам**: `docs/specs/StepX.Y-<Name>.md` (например, `Step1.1-SetupAndModels.md`). Содержит цель, действия, код, тесты, масштабируемость для каждого шага.

## Описание для человека, который будет работать с ИИ
- **Как использовать этот промт**:
  1. Загрузите проект (локально или GitHub) и ключевые документы (`InvestmentAdvisorDetailedPlanWithUI.md`, `DevelopmentApproachAndIndex.md`, `ModularityConcept.md`).
  2. Укажите текущую стадию, шаг, статус, задачу, ошибки и ресурсы (см. пример ниже).
  3. Вставьте промт в чат ИИ (Grok или другой).
  4. ИИ задаст уточняющие вопросы — ответьте, чтобы он начал кодинг.
  5. Проверьте код, тесты и коммит в Git.
  6. Если проблема, обновите промт с новыми деталями.
- **Советы**:
  - Подгружайте конкретный модуль (e.g., `src/data/providers.py`) для фокуса.
  - Если ИИ не понимает, предоставьте исходный код или логи.
  - Следите за регламентом: PEP8, pydantic, ABC, coverage >80%.
  - Для команды: Поделитесь промтом как инструкцией, используйте Git PR для review.
