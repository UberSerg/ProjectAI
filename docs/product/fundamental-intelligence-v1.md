# Product — Fundamental Intelligence V1

## What users see

- **Companies** (`/fundamentals`): issuer list + detail with **РСБУ** badge when FNS RAS
  reports exist, publication / `known_at`, fact table, honest empty when unmapped.
- **Banks**: clear copy that FNS RAS V1 does not support FI metrics.
- **Portfolio**: read-only equity fundamental coverage (no sync on page open).
- **System → Data Coverage**: RAS/FNS counts, Dataset V3 gate, FNS process flag.

## What Kraken does *not* claim

- IFRS from FNS
- Bank fundamentals from GIR BO
- Dividend / total-return readiness without an accepted disclosure provider
- Dataset V3 training readiness from fundamentals alone
