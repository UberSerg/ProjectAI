# KRK-RISK-0003 — Пропуск цены не равен нулю

## Суть

Нет рыночной цены — нет права показать 0 ₽ как стоимость бумаги и нет права назвать частичный NAV полным. На карточке хаба это исправлено PR #91. Инвариант остаётся обязательным везде.

## Как проявляется

До исправления #91 независимый разбор нашёл ложный 0 ₽ при сбое оценки и щель тестовых портфелей при явных id. После merge путь хаба должен отдавать full / partial / unavailable. Принудительный скриншот partial был overlay и не доказывает ответ API.

## Почему опасно

Ноль завышает или занижает капитал, портит доходность и ребаланс. Новый экран легко повторит ошибку, если править только хаб.

## Причина

Лёгкий список сначала жил без цен. Первая попытка добавить сумму подставила ноль на неизвестное. Это закрыто кодом #91 `512628b2798bc81f91a480769e08adfcdbe6169d`. Другие будущие суммы (XIRR, бенчмарк, P&L решения) ещё не написаны и обязаны унаследовать правило.

## Как должно работать

Известная сумма и качество оценки разделены. Неполное покрытие видно. Депозит и вывод не становятся прибылью. Тестовый портфель не всплывает в обычном списке без явного включения.

## Предлагаемое исправление

Для хаба нового PR не требуется, пока регрессия не вернётся. Для каждой новой денежной поверхности — тест «нет цены → не ноль». Карточка в статусе watch, не done: правило шире одного экрана.

## Критерии закрытия

Карточка может стать done только если появится общий контракт оценки и тесты на основных денежных экранах. Пока Gate 1 не начат, статус watch честнее, чем done.
