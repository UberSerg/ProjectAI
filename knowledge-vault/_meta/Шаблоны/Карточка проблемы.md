# Шаблон: карточка проблемы

```yaml
---
id: KRK-BUG-0000
type: bug # bug | risk | debt | ux | data | ops
module:
priority: P0 # P0 | P1 | P2 | P3
status: open
evidence_level: verified # verified | reported | hypothesized
created: YYYY-MM-DD
owner: unassigned
github_issue:
github_pr:
last_checked: YYYY-MM-DD
---
```

Обязательные разделы: Суть, Как проявляется, Почему опасно, Причина, Как должно работать, Предлагаемое исправление, Критерии закрытия, История, Связанные задачи, Подтверждающие источники.
