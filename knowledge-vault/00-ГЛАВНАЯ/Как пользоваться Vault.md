## Для Owner / планировщика

1. Откройте [[ДОМ]].
2. Смотрите [[Kraken сегодня]] и [[Сейчас]].
3. Открытые блокеры — [[Критические проблемы]].
4. Выбор следующего этапа — [[Roadmap Kraken]] + Master Context.

## Для нового разработчика

1. [[Первый день разработчика]]
2. [[Kraken за 30 минут]]
3. [[Карта всей системы]]
4. Один паспорт модуля по вашей задаче
5. Связанные [[Все проблемы]] и [[ВЕСЬ БЭКЛОГ]]

## Для Cursor / AI-агента

1. Прочитать [[Правила ведения Vault]] и [[Карта ответственности]]
2. Не писать в чужой каталог
3. После значимого изменения — 4 направления (история / модуль / проблема-задача / roadmap)
4. Не объявлять merge/acceptance без GitHub / Owner

## Wikilinks

Используйте wikilinks вида `[[ДОМ]]` или `[[Карта всей системы]]`. Плагины Obsidian необязательны: индексы — обычный Markdown.

## Что не делать

- Не копировать секреты
- Не считать заметку Vault доказательством merge
- Не стартовать Epic без Owner approval
