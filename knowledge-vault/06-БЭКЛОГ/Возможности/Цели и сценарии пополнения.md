# Возможность — цели и пополнение

## Зачем

Человек хочет видеть, к чему ведёт ежемесячное пополнение, не путая план с фактом.

## Текущее состояние

Daily Decision V2 уже умеет разложить новый капитал на сценарии, не меняя портфель. Это кусок 1.01, не модуль целей Snowball. `implementation_status: partial` только про уже смерженный разбор нового капитала. Цели с горизонтом и допущениями не начаты.

## Желаемый результат

Цель показывает допущения. Сценарий не создаёт операций. «Ничего не делать» остаётся видимым исходом.

## Техническая реализация

Над учётом Gate 1. Не исполнять предложения.

## Зависимости

KRK-EPIC-0003.

## Критерии готовности

Пользователь отличает цель, сценарий и проведённую операцию. Тест не создаёт строку журнала из цели.

## Риски

Нарисовать цель как обещание доходности.

## Связанные проблемы

Нет отдельной карточки. Рядом инвариант «совет не равен сделке».

## История выполнения

Частично живёт с 2026-09-28. Продуктовая цель Gate 3 не стартовала.

## Подтверждения
