# Возможность — бенчмарк

## Зачем

Инвестор хочет видеть портфель рядом с индексом, а не только абсолютную сумму.

## Текущее состояние

В коде есть сравнения и ребаланс как более ранние экраны. Выровненный по датам и валюте ряд с честным total return индекса в Gate 3 не отмечен готовым. Возможность не авторизована к реализации.

## Желаемый результат

Общий календарь торговых дней, объяснение пропусков, дивиденды индекса только если они правда есть в ряде. Взнос на портфель не рисуется как обгон индекса.

## Техническая реализация

После словаря доходности из эпика себестоимости. Отдельный PR аналитики.

## Зависимости

KRK-EPIC-0003, затем контракт внутри KRK-EPIC-0005.

## Критерии готовности

Фикстура с дырой в котировке не получает нулевую доходность и не получает «портфель победил».

## Риски

Смешать price return портфеля и total return индекса.
