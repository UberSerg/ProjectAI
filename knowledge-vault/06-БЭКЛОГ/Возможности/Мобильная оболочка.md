# Возможность — мобильная оболочка

## Зачем

Основной сценарий должен жить на ширине телефона, не только на широком desktop V1.0.

## Текущее состояние

V1.0 описан как тёмный desktop. Смотр 390 и 320 входит в Gate 0 как проверка, не как PWA. Gate 5 говорит про отзывчивость и возможный офлайн-снимок позже. Agent 09 на 30 октября ещё не сдал независимую мобильную приёмку журнала.

## Желаемый результат

Нет горизонтального развала основных экранов. PWA и офлайн не обещаются этой идеей.

## Техническая реализация

Сначала смотр KRK-TASK-0012. Починка переполнения отдельными UI-PR. PWA — только если Gate 5 когда-нибудь выберут.

## Зависимости

KRK-TASK-0001 и смотр.

## Критерии готовности

Для Gate 0 достаточно отчёта по 390 и 320. Для идеи «зрелая оболочка» нужен отдельный выбор Owner. Сейчас критерий идеи не выполнен.

## Риски

Начать PWA вместо починки журнала и mount.
