# KRK-TASK-0007 — Создание портфеля

## Зачем

Если портфель создан, а список не перечитался, UI не должен предлагать создать его ещё раз.

## Текущее состояние

#86 защитил путь контекста и смержен `0846bd896f33fea049377671e0d4888eef9565ba` / fix `775237298f615cb32f75da9ca7b9cd8250bbbef2`. Страница портфеля, по спецификации 28 октября, всё ещё зовёт create и refresh напрямую. Повторное чтение файла 23 ноября не делалось: перед стартом сверить, не исчез ли обход.

## Желаемый результат

Один POST. Неудачный GET списка не откатывает созданную книгу и не шлёт второй POST.

## Техническая реализация

Переиспользовать `PortfolioContext.createPortfolio()` или эквивалент. Не откатывать #86.
