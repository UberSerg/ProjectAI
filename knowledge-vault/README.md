# KRAKEN Knowledge Vault

Человекочитаемая база знаний Kraken / ProjectAI **внутри этого репозитория**.

## Открыть в Obsidian

Укажите папку vault:

```text
<корень-клона-ProjectAI>/knowledge-vault
```

Например: `E:\!AI\ProjectAI-wt-knowledge-vault\knowledge-vault`

Опционально: junction `E:\kraken Vault` → эта папка (один SoT, без второй копии).

## Источники истины

См. `00-ГЛАВНАЯ/Источники истины.md` и правило `.cursor/rules/45-knowledge-vault.mdc`.

Кратко: GitHub = код/PR; Master Context = статус; этот Vault = смысл, история, проблемы, backlog.

## Синхронизация

1. **В начале работы:** `git pull` / обновить ветку — подтянуть чужие правки Vault.
2. **После значимого изменения:** обновить заметки → commit → push.
3. Не вести параллельную «локальную энциклопедию» вне git.

## Старт
