## Что было раньше
Инженерные теги v0.x и набор модулей без одной человеческой версии «Kraken V1.0».

## Какая была проблема
Нельзя было отличить технический прогресс от объявленного релиза. История в UI не имела первой неизменяемой записи.

## Что изменили
PR #60 — восстановление EOD Shadow, catch-up, виды USER/OWNER (`10f7498c408d3265be3d5e36a9bdf9de46c4771d`).  
PR #61 — versioning и About (`abbb6718cce0bc3cc21cb396162dd99be031c0a9`).  
PR #62 — человеческий changelog. Манифест хранит дату 2026-09-27, тег `v1.0.0`, SHA выше. В комментарии манифеста указан `published_at` GitHub Release `2026-09-27T09:43:33Z`. Этот timestamp взят из комментария файла на main, заново через API релизов не перепроверялся.

## Почему выбрали такое решение
Релиз объявляется явно. Номер не прыгает от каждого PR.

## Что получили
Первая строка `KRAKEN_RELEASES` и текст changelog: портфель, рекомендации, догон MOEX, Shadow, честные пустые состояния, USER/OWNER как показ.

## Как проверили
Файлы `VERSION`, `CHANGELOG.md`, `manifest.ts` на `origin/main`. Live smoke V1.0 в этом сеансе не повторялся.

## Что осталось
Следующие продуктовые номера 1.01–1.05 без тегов. Технический VERSION так и остался 1.0.0.
